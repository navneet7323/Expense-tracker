# 💰 Expense Tracker App

A simple, responsive, and user-friendly Expense Tracker built using **Vanilla JavaScript** and **Bootstrap 5**. This application allows users to manage their daily expenses by adding, editing, and deleting items while using browser `localStorage` to save entries persistently across page reloads.

## 🚀 Features

- **Add Expenses:** Easily record expense amounts, descriptions, and categories.
- **Local Storage Integration:** Automatically saves expenses in browser storage so data isn't lost on refresh.
- **Edit & Delete:** Update existing entries or clear completed items with a single click.
- **Responsive Design:** Styled using Bootstrap 5 for a clean look across all mobile and desktop devices.

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** / **Bootstrap 5** (via CDN)
- **JavaScript (ES6+)** — DOM Manipulation & LocalStorage API
